# 松鼠大作战 · 4399 提交说明

这个目录是给 **4399 开放平台 H5 小游戏** 用的兼容包，已经做了以下处理：

- 禁用 Service Worker / PWA 缓存，避免 4399 更新版本后玩家仍看到旧文件；
- 隐藏「分享给好友」「全屏」「安装到桌面」按钮，避免和 4399 平台自带能力冲突；
- 预留 4399 常驻平台标识；
- 游戏仍是纯静态文件，无外部请求、无 `window.open`，符合平台基本的审核要求。

> 这是**未接 4399 广告 SDK** 的版本，适合先过内容审核、跑通上线流程。要接 IAA 激励广告，需要按 4399 后台/对接群提供的最新文档再接入。

---

## 一、提交前准备

### 1. 4399 开发者账号

1. 打开 **https://open.4399.cn/**（或 `https://www.4399api.com/`）；
2. 注册开发者账号，完成实名认证；
3. 登录后台，创建游戏，类型选 **HTML / H5**；
4. 填写游戏名称、游戏宽高、简介、分类、标签等信息。

游戏宽高建议填 **1280 × 720**（16:9）。游戏本身是响应式的，手机端会自动适配。

### 2. 官方 4399 标识

4399 要求游戏内保留常驻平台标识。请从 4399 开放平台文档/后台下载官方 logo，保存为：

```text
icons/4399-logo.png
```

如果暂时没有官方 logo，页面会显示「4399 小游戏」文字兜底；**正式提审前建议换成官方素材**。

### 3. 素材

准备以下素材（具体尺寸以 4399 后台「素材需求」页为准）：

- 游戏图标：可直接用 `icons/icon-512.png`；
- 游戏截图：3–5 张，建议横屏 16:9，展示菜单、关卡、踩敌人、收集橡果等画面；
- 游戏简介：一句话 + 3–5 条玩法说明；
- 分类/标签：休闲、动作、闯关、收集、松鼠；
- 如平台要求：软著/著作权授权材料、隐私政策、适龄提示说明。

### 4. 打包

4399 只接受 **zip**，且 **zip 根目录必须直接是 `index.html`**。

正确结构：

```text
squirrel-quest-4399.zip
├── index.html
├── style.css
├── engine.js
├── game.js
├── 4399.css
├── 4399-boot.js
├── manifest.webmanifest
└── icons/
```

不要出现 `web-4399/index.html` 这种多一层目录的结构。

## 二、后台上传与审核

1. 登录 4399 开放平台；
2. 进入 **游戏管理 → 游戏素材 → 游戏主文件**；
3. 上传 `squirrel-quest-4399.zip`；
4. 上传图标、截图、简介等素材；
5. 在平台的预览/测试环境里完整玩一遍：
   - 主菜单能开始游戏；
   - 手机横屏、竖屏都能操作；
   - 音效、暂停、关卡切换正常；
   - 没有外部跳转、没有 404 资源；
6. 点击 **提交审核**；
7. 审核通过后，按平台流程签合同、配置结算信息；
8. 如果要做 IAA，联系 4399 商务/运营开通广告权限，再按最新文档接入激励视频等广告。

审核时长没有公开 SLA，通常以后台/商务反馈为准；建议预留几个工作日到两周。

---

## 三、IAA 广告接入（审核通过后再做）

这个版本没有广告代码。4399 的 H5 小游戏广告接入一般需要：

1. 从 4399 后台/对接群获取最新的 **HTML5 小游戏激励广告 SDK/API 文档**；
2. 在 `index.html` 里按文档插入广告脚本；
3. 在游戏里选择广告触发点，例如：
   - 复活；
   - 结算双倍分数；
   - 每日奖励；
   - 关卡失败后的额外机会；
4. 处理「今日次数用尽」「广告加载失败」「用户中途关闭」等状态；
5. 通知商务开通广告权限后，在测试环境验证，再重新提审。

**不要在没拿到官方文档前猜 API 名字**；不同版本 SDK 的方法名可能不同。

## 四、常见驳回点

- zip 根目录没有 `index.html`；
- 游戏内缺少 4399 常驻标识；
- 游戏里有外部链接、`window.open`、第三方广告；
- 素材尺寸/格式不符合后台要求；
- 游戏名称、软著名称、后台填写名称不一致；
- 手机端按钮被遮挡、无法操作；
- 未按要求接入实名/防沉迷/隐私说明（以平台要求为准）。

## 五、本地测试

```bash
cd web-4399
python3 -m http.server 8080
# 打开 http://localhost:8080
```

注意：本地测试时 Service Worker 已被禁用，这是预期行为；4399 线上也不需要它。

---

## 六、更新版本

修改文件后重新打 zip，在 4399 后台更新「游戏主文件」并重新提审即可。因为没有 Service Worker，玩家不会卡在旧缓存。
