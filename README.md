# 🐿️ 松鼠大作战 (Squirrel Quest)

一款基于 **Python + Pygame** 开发的横版平台动作闯关游戏。玩家操控可爱的小松鼠，在森林关卡中收集橡果、踩踏敌人、利用弹簧跳跃，完成全部 3 个关卡的挑战！

> 📱 **手机网页版**：同一套玩法已移植为纯静态网页，并扩展到 **80 个关卡 / 8 个世界**（种子化生成、无重复布局），新增金橡果、尖刺、检查点、连击倍率与关卡选择。支持触屏、横竖屏、PWA 离线安装、成绩卡与挑战链接分享，无需构建，直接托管即可发给好友。详见 [`web/README.md`](web/README.md)。

## 🚀 快速开始

### 环境要求
- Python 3.8+
- pygame >= 2.0

```bash
pip install pygame
```

> Python 3.14 及以上暂时没有 `pygame` 官方预编译轮子，可改用兼容包 `pygame-ce`（`import pygame` 不变，代码无需修改）：
>
> ```bash
> pip install pygame-ce
> ```

## ✨ 核心玩法

### 🌰 收集橡果
关卡中散落着金色橡果，**收集全部橡果**即可通关当前关卡。每个橡果 +50 分。

### 🦶 踩敌人
从上方跳到敌人头上即可消灭它！类似经典马里奥的踩踏机制，每个敌人 +100 分。

### 🔨 举起投掷（特色系统！）
靠近敌人按 **F** 键可以将其举起，再按 **F** 投向其他敌人，实现 **连锁消灭**，每次 +200 分！

### 🔴 弹簧道具
红色弹簧可以将松鼠弹射到高处，到达普通跳跃无法触及的平台。

### ❤️ 生命系统
初始 3 条生命，碰到敌人侧面或下方会损失生命并短暂无敌。掉出地图也会损失生命。

## 📈 难度设计

三关由易到难，所有橡果都放在平台或地面上，保证可以正常拿到：

| 关卡 | 橡果 | 敌人 | 敌人速度 | 平台与地形 |
|------|------|------|----------|------------|
| 1 | 7  | 2 | 1.4 | 4 格宽平台、2 格落差，轻松上手 |
| 2 | 10 | 4 | 1.8 | 3 格宽平台，开始出现 3 格落差 |
| 3 | 13 | 6 | 2.2 | 连续高台、更窄的平台，多处 3 格落差 |

## 🏗️ 项目结构

```
squirrel_fight/
├── main_game.py       # 🎨 主程序 / GUI（渲染、动画、粒子、HUD）
├── game_engine.py     # ⚙️ 核心引擎（物理、碰撞、实体、关卡数据）

```

### 架构设计

```
┌─────────────────────────────────────────┐
│           main_game.py (GUI)            │
│  ┌──────────┐  ┌──────────┐           │
│  │  Squirrel │  │  Particle│           │
│  │  Game     │  │  System  │           │

│        │                                 │
│  ┌─────▼──────────────────────────┐     │
│  │      game_engine.py (引擎)      │     │
│  │  ┌────────┐  ┌──────────────┐  │     │
│  │  │ Player │  │  TileMap     │  │     │
│  │  │ Enemy  │  │  Acorn       │  │     │
```

- **引擎层** (`game_engine.py`)：纯逻辑，无 GUI 依赖，可被任何前端复用
- **表现层** (`main_game.py`)：pygame 渲染、粒子系统、动画、UI

## 🔧 扩展方向

项目预留了良好的扩展接口，可以轻松添加：

- **🎵 音效系统** — 在 `SquirrelGame` 中添加 `pygame.mixer`
- **🐦 新敌人类型** — 继承 `Enemy` 类，添加新的 `etype`
- **🧱 更多方块类型** — 在 `TileMap.tile_type()` 中扩展
- **💾 存档系统** — 序列化 `score` / `level` 到文件
- **🏅 排行榜** — 记录最高分
- **🎨 精灵图** — 替换矢量绘制为图片资源
